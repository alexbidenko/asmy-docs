---
title: Решение проблем
description: С чего начать, если панель, сайт, вход или обновление не работают.
---

Начинайте с исходной ошибки и текущего состояния. Многократный запуск установщика, очистка Docker и удаление volumes могут затруднить восстановление.

## Панель не открывается

1. Проверьте DNS домена панели, включая AAAA-запись, если она есть.
2. Проверьте доступность самого сервера по SSH или через консоль провайдера.
3. На сервере убедитесь, что Docker работает, а диск не заполнен.
4. Проверьте контейнеры Asmy и Caddy и их логи.
5. Убедитесь, что 80/443 не заняты другим web-сервером и доступны извне.

Безопасные команды для первичной диагностики:

```bash
docker info
docker ps -a --format 'table {{.Names}}\t{{.Image}}\t{{.Status}}'
df -h
```

Для обычной Compose-установки панель и Caddy имеют следующие имена:

```bash
docker logs --tail 200 admire-server-manager_application
docker logs --tail 200 caddy_web_server
```

В Swarm сначала посмотрите сервисы и задачи:

```bash
docker service ls
docker service ps admire-server-manager_application --no-trunc
docker service logs --tail 200 admire-server-manager_application
```

Команды Swarm выполняются на manager-узле. Для Caddy найдите его сервис в `docker service ls`; имена контейнеров задач отличаются от Compose.

Если одновременно недоступны SSH и web-порты, ошибка может быть за пределами Asmy. Используйте консоль провайдера и поддержку хостинга; повторное развёртывание панели не исправляет сетевую недоступность хоста.

## Ошибка сертификата или HTTPS

Проверьте, что домен указывает на сервер, запросы попадают в Caddy, а HTTP/HTTPS доступны извне. Для каждого имени, включая отдельно добавленный `www`-домен, нужна DNS-запись. Посмотрите точный ответ центра сертификации в логах Caddy.


Общие условия автоматического HTTPS описаны в [документации Caddy](https://caddyserver.com/docs/automatic-https). Не обходите предупреждение браузера для ввода рабочего пароля: сначала устраните причину.

## Сайт отвечает 502

Проверьте состояние web-контейнера и его логи. Затем Alias, внутренний порт и общую сеть:

```bash
docker network inspect server
```

Caddy и приложение должны быть подключены к этой сети. `localhost` из Caddy не ведёт в другой контейнер. Если приложение слушает только loopback внутри собственного контейнера, одной общей сети недостаточно.

Подробный пример — [«Доменные имена»](/usage/constructor).

## Настройки сохранены, но сайт не изменился

Данные в БД и действующая конфигурация Caddy могут различаться. Примените изменения через «Перезагрузить» в форме либо «Перезапустить» в списке проектов. Затем проверьте сайт и логи.

Если в конфигурации есть ошибка, найдите последнее изменение, особенно ручные блоки и заголовки. Не удаляйте все проекты, чтобы вернуть доступ. Резервное восстановление Caddy в коде не гарантирует автоматического выхода из любой неисправности.

## Ошибка доступа к данным Caddy

Перед заменой web-сервера Asmy проверяет доступ к существующему хранилищу
сертификатов от пользователя Caddy (UID 100, GID 101). Если проверка не прошла,
применение останавливается и прежний Caddy не заменяется. Посмотрите исходную
ошибку в логах Asmy и владельцев файлов в его Caddy data volume.

Не удаляйте volume и не устанавливайте права 0777: это может потерять сертификаты
или открыть приватные ключи. Исправлять нужно конкретного неверного владельца или права
доступа, предварительно сохранив копию данных. `autosave.json` для штатного запуска
Asmy не используется; текущий Caddy запускается из Caddyfile.

## Не получается войти

- Убедитесь, что открыли именно свою панель и используете её аккаунт.
- После перехода на версию 3.6 обновите вкладку и войдите заново: старые токены больше не принимаются.
- Проверьте разрешение cookies и отсутствие одновременно открытых вкладок с разными аккаунтами в одном профиле браузера.
- Ошибка 401 означает, что запрос не принят как действующая сессия; потребуется вход. Ошибка 503 может указывать на временную недоступность БД, а не неверный пароль.
- Если используется дополнительный reverse proxy, он не должен менять публичную схему/host так, чтобы проверка Origin или secure-cookie перестала соответствовать адресу панели.

Если пароль забыт, автоматического восстановления по email сейчас нет. Нужен администратор сервера; удалять БД или повторно устанавливать панель вместо восстановления нельзя.

## Пустой список

В проектах проверьте поиск и вкладки активных/архивных записей, членство пользователя и Alias доменов. Для ресурсов проекта проверьте также подключение хранилищ к нужным контейнерам.

В разделе «Сети» нажмите обновление списка: известна проблема его первой загрузки.

## Обновление не завершилось

Проверьте логи основного приложения и контейнера установщика:

```bash
docker ps -a --filter name=admire-server-manager-installer
docker logs --tail 200 admire-server-manager-installer
```

Установщик запускается отдельно. Успешный ответ команды обновления и окно в браузере не доказывают завершение установки. Сравните фактическую версию в настройках и образы/состояние контейнеров.

Ошибки HTTP, загрузки образов, нехватки места или инициализации сети нужно устранить до повторного запуска. При неоднозначном IP для `swarm init` следуйте [инструкции установки](/getting-started/installing#почему-swarm-включается-и-в-режиме-compose), не пересоздавая существующий кластер.

## Что собрать для обращения за помощью

Укажите текущую и целевую версии, Compose или Swarm, версию Docker, последнее действие и исходный текст ошибки. Приложите небольшой фрагмент логов вокруг сбоя.

Уберите из материалов пароли, cookies, токены, `.env`, приватные URL и персональные данные. Даже диагностические логи и Docker inspect могут содержать секреты. Не отправляйте всю БД или файловое хранилище без отдельной необходимости.

## Форма сообщает об ошибке поля

Asmy показывает пояснение рядом с полем после ввода или попытки сохранения.
Кнопка сохранения остаётся доступной, но при обнаруженных ошибках запрос не
отправляется: исправьте отмеченные поля и нажмите её снова. Введённые данные
при отказе сохраняются. Если ошибка находится на другой вкладке формы домена,
её название становится красным; активная вкладка сохраняет зелёный цвет.
Перейдите на красную вкладку, чтобы увидеть пояснение у поля. Общие ошибки
сервера или сети показываются отдельным уведомлением.

Ограничения небольших имён не распространяются на весь текст конфигурации:
ручные блоки Caddy и файловый редактор допускают большие значения. Не обрезайте
рабочую конфигурацию вслепую, если она перестала сохраняться после обновления;
сохраните исходный текст и уточните причину ошибки.
