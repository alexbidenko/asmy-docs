Asmy работает с контейнерами, которые уже есть на сервере. Развёртывайте приложения через их Compose-файлы, Swarm или другой принятый у вас способ. Создание проекта в панели не создаёт контейнер автоматически.

## Где найти контейнер

Откройте общий раздел **«Контейнеры»** либо проект → **«Контейнеры»**. Общий список группирует ресурсы Docker и показывает состояние, имя и образ. Имена и названия образов можно скопировать нажатием на них.

![Контейнеры демонстрационного приложения Lumen](/images/containers.jpg)

Ресурсы группируются с учётом имён и меток Docker Compose; проектная связь также зависит от адресов проксирования. [Как устроена связь с проектом](/usage/projects#как-появляются-контейнеры).

Статус `running` означает, что процесс контейнера работает. Он не доказывает исправность сайта, успешную миграцию или доступность БД. Если в образе настроен Docker healthcheck, в статусе может отображаться его состояние.

## Действия

| Действие | Результат |
| --- | --- |
| Дополнительная информация | Открывает сведения о контейнере и подробности Docker inspect. |
| Логи | Показывает вывод приложения; [подробнее](/docker/logs-terminal). |
| Запустить | Запускает остановленный контейнер. |
| Остановить | Останавливает процесс, что может сделать приложение недоступным. |
| Перезапустить | Перезапускает существующий контейнер. Это не загрузка нового образа. |
| Удалить | Удаляет контейнер после подтверждения. Не используйте как способ остановки. |
| Терминал | Открывает командную оболочку внутри работающего контейнера, если действие доступно. |

Перед остановкой проверьте назначение ресурса. Остановка БД или обработчика задач может повлиять на другие контейнеры, даже если web-контейнер продолжает работать.

Файлы в записываемом слое контейнера могут быть потеряны при удалении. Важные данные должны храниться в подходящих постоянных хранилищах и иметь резервные копии.

## Compose и Swarm

В Compose контейнер управляется напрямую. После его удаления повторный `docker compose up` может создать его снова по исходной конфигурации.

В Swarm контейнер — задача сервиса. Swarm может создать замену удалённой задаче; для управления приложением учитывайте сам сервис и его желаемое состояние. Поэтому часть кнопок отдельных контейнеров скрыта. Удаление **сервиса** — отдельная операция, которая убирает его задачи.

Не включайте небезопасный режим только ради появления скрытой кнопки. Сначала определите, какой объект нужно изменить: контейнер, сервис или исходный файл развёртывания.

## Служебные ресурсы

Контейнеры Asmy, его PostgreSQL и Caddy относятся к работе самой панели. Их остановка или удаление может лишить вас доступа к интерфейсу либо данным настройки. Расширенные действия над ними ограничены интерфейсом; параметр [«Небезопасный режим»](/operations/maintenance#настройки) ослабляет часть этих ограничений.

Доступность кнопок зависит от [роли](/usage/roles). Эти ограничения интерфейса не следует считать полной серверной изоляцией пользователей.
