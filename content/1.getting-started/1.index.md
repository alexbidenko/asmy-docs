Asmy (Admire Server Manager) — панель управления Linux-сервером, на котором приложения работают в Docker. Она помогает открыть приложение по доменному имени, посмотреть контейнеры и их логи, работать с файлами в хранилищах и дать коллегам доступ к проекту.

Asmy устанавливается на ваш сервер. Приложения и их данные остаются на нём; для повседневной работы вы открываете панель в браузере.

## Как это устроено

| Сущность | Для чего нужна |
| --- | --- |
| Проект | Объединяет домены, участников и связанные ресурсы приложения. |
| Домен | Описывает, куда направлять запросы посетителей: в контейнер, на другой сайт или на страницу перенаправления. |
| Контейнер | Запущенный компонент приложения: например, web-сервер или обработчик задач. |
| Хранилище | Docker volume с файлами, которые должны сохраняться независимо от пересоздания контейнера. |
| Caddy | Web-сервер перед приложениями. Asmy формирует для него конфигурацию доменов и HTTPS. |

Обычно работа выглядит так: вы запускаете приложение через Docker Compose или Swarm, создаёте проект в Asmy и добавляете домен, указывающий на web-контейнер. После применения конфигурации сайт становится доступен по этому домену.

## Важные границы

Asmy имеет расширенный доступ к Docker и файловой системе сервера. Доступ к панели стоит предоставлять только доверенным людям. Текущие роли помогают организовать работу команды, но **не обеспечивают строгую изоляцию недоверенных пользователей или клиентов**. Подробнее — в [описании прав](/usage/roles#ограничения-разграничения-доступа).

Панель запускается без privileged и не подключает корневую папку сервера. Для файлового менеджера ей доступен каталог Docker volumes. Docker socket сохраняется: он нужен управлению контейнерами и по-прежнему даёт панели административные возможности на сервере.

Asmy не заменяет резервное копирование приложений, настройку операционной системы и контроль доступности сервера. Обновления самой панели выполняются автоматически; [как они работают](/usage/updating) полезно прочитать до установки на рабочий сервер.

Иллюстрации в руководстве сделаны на демонстрационном стенде. Названия Lumen, адреса `example.com` и содержимое файлов вымышлены; элементы интерфейса настоящие.
