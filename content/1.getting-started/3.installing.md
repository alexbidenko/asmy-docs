---
title: "Установка и запуск"
description: "Для установки и запуска Asmy необходимо выполнить всего одну команду в терминале:"
---

```bash
bash <(curl -Ls https://raw.asmy.pro/setup.sh)
```

После выполнения команды запустится интерактивный установщик, который задаст несколько вопросов, необходимых для настройки и запуска программы.

Пример вопросов, которые могут быть заданы:
- Введите ваш email (необходим для генерации сертификатов безопасности).
- Введите адрес для Asmy (без https и слешей, например, `admin.example.com`).
- Выберите режим работы Docker (Swarm или Compose).
- Использовать ли HTTPS для Asmy? (Да / Нет).

На основании ваших ответов установщик автоматически выполнит всю настройку и запустит программу.

Для общей сети контейнеров установщик включает Docker Swarm, если он ещё не
инициализирован. Это требуется и при выборе Compose: само приложение продолжает
запускаться через Compose. Существующий кластер и сеть не пересоздаются.
Если Docker не может выбрать IP-адрес, выполните `docker swarm init --advertise-addr <IP-или-интерфейс>`
с адресом сервера и повторите установку.

После завершения установки:
- Asmy будет доступен по указанному адресу.
- Для первого входа используйте email, который вы указали при установке, и пароль `admin`. После входа Asmy предложит сменить этот пароль: укажите `admin` как текущий пароль, затем новый пароль и его повтор.
- При смене пароля остальные входы в ваш аккаунт завершаются. Текущий вход сохраняется.

Сессия действует до 7 дней без активности и максимум 30 дней от входа. После завершения сессии потребуется войти снова.

Теперь ваш Asmy полностью готов к использованию! 🎉
